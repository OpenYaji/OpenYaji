# Icon sources

Technology glyphs are from [Devicon Plain](https://github.com/devicons/devicon) (MIT), distributed through [Iconify](https://github.com/iconify/icon-sets/blob/master/json/devicon-plain.json). The GitHub glyph is from [CoreUI Brands](https://github.com/coreui/coreui-icons) (CC0-1.0).

React, Tailwind CSS, and VS Code use [Skill Icons](https://github.com/tandpfun/skill-icons) (MIT). License notices are included in `icon-licenses.txt`.

Express uses its text abbreviation; Vercel uses its triangle mark. LangChain, Databricks, and Vector Databases use generic chain, data-layer, and database symbols, not official brand logos. All technology names remain visible in the tiles.

Brand names and trademarks belong to their respective owners. Tile backgrounds and typography are custom profile artwork.
