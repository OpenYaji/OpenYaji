# Icon sources

Technology glyphs are from [Devicon Plain](https://github.com/devicons/devicon) (MIT), distributed through [Iconify](https://github.com/iconify/icon-sets/blob/master/json/devicon-plain.json). The GitHub glyph is from [CoreUI Brands](https://github.com/coreui/coreui-icons) (CC0-1.0).

React, Tailwind CSS, and VS Code use [Skill Icons](https://github.com/tandpfun/skill-icons) (MIT). License notices are included in `icon-licenses.txt`.

Express uses its text abbreviation; Vercel uses its triangle mark. LangChain, Databricks, and Vector Databases use generic chain, data-layer, and database symbols, not official brand logos.

`technologies.svg` and `technologies-mobile.svg` collect 45 local glyphs into a single colored grid, including Kubernetes and NGINX. Colors identify each technology; Figma uses separate colored shapes. NGINX uses a custom vector drawing of its green hexagon and white N. Each pack embeds its paths and includes every technology name in its description, without external image requests. The README also lists the names in the image alternative text.

The icon-only links in `social/` use custom globe and envelope drawings, simple platform marks, and the X wordmark glyph. Facebook, LinkedIn, and Instagram use the user-selected GIFs listed in `motion-sources.md`, with local SVG icons for reduced-motion preferences. Link destinations and accessible names are provided in the README.

Brand names and trademarks belong to their respective owners. Tile backgrounds and typography are custom profile artwork.
